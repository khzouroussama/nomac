# Corpus results

A check is *identical* when nomac's output matches Xcode's byte for byte after the path rewrites in docs/adr/0004-reference-artifacts.md. *Unsupported* checks use an xcodebuild mode nomac does not reproduce yet and count as failures. *Refused* checks are tasks of Xcode's build whose tool nomac stops on, naming what it does not reproduce yet; they count as failures too. *Reference failed* means Xcode itself failed, or the capture did not keep the files, so nothing was compared. A build product is *equivalent* when it comes from a compiler, has Xcode's structure and differs only in documented ways (docs/adr/0101-compiled-code-and-xcodes-compilers.md); it passes as identical ones do. Each progress line is measured as corpus/corpus.json's `progress` says (docs/VERIFICATION.md "Progress").
